# 校园信息聚合论坛系统（校园通）数据库设计文档v1.4

## 1. 数据库概述

### 1.1 设计原则
- 采用关系型数据库设计
- 遵循第三范式（3NF）
- 合理的表结构和关系
- 适当的索引设计
- 考虑性能和扩展性
- 数据完整性和安全性

### 1.2 数据库选择
- 数据库：MySQL
- 版本：9.4
- 字符集：UTF-8mb4（支持表情符号）
- 排序规则：utf8mb4_unicode_ci

### 1.3 核心表结构

| 表名 | 描述 | 关系 |
| --- | --- | --- |
| users | 用户信息 | 1:N (posts, comments, likes, reports, follows, favorites, browsing_history) |
| categories | 板块分类 | 1:N (posts) |
| posts | 帖子内容 | N:1 (users, categories), 1:N (comments, likes, reports, favorites, browsing_history) |
| comments | 评论信息 | N:1 (users, posts), 1:N (likes, reports) |
| likes | 点赞记录 | N:1 (users, posts/comments) |
| reports | 举报记录 | N:1 (users, posts/comments) |
| follows | 用户关注 | N:1 (users) |
| favorites | 帖子收藏 | N:1 (users, posts) |
| browsing_history | 浏览历史 | N:1 (users, posts) |

## 2. 详细表设计

### 2.1 用户表（users）

| 字段名 | 数据类型 | 约束 | 描述 |
| --- | --- | --- | --- |
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 用户ID |
| username | VARCHAR(50) | NOT NULL, UNIQUE | 用户名 |
| email | VARCHAR(100) | NOT NULL, UNIQUE | 邮箱（学校邮箱@xx.edu.cn） |
| password | VARCHAR(255) | NOT NULL | 密码（bcrypt加密） |
| avatar | VARCHAR(255) | NULL | 头像URL |
| bio | TEXT | NULL | 个人简介 |
| role | VARCHAR(20) | NOT NULL, DEFAULT 'student' | 用户角色 |
| status | VARCHAR(20) | NOT NULL, DEFAULT 'active' | 用户状态 |
| reputation | INT | NOT NULL, DEFAULT 100 | 信誉值 |
| post_count | INT | NOT NULL, DEFAULT 0 | 发帖数 |
| comment_count | INT | NOT NULL, DEFAULT 0 | 评论数 |
| show_profile | BOOLEAN | NOT NULL, DEFAULT TRUE | 谁可以查看我的个人资料 |
| allow_messages | BOOLEAN | NOT NULL, DEFAULT TRUE | 谁可以给我发送私信 |
| allow_follow | BOOLEAN | NOT NULL, DEFAULT TRUE | 允许他人关注我 |
| show_posts | BOOLEAN | NOT NULL, DEFAULT TRUE | 谁可以查看我的帖子 |
| save_history | BOOLEAN | NOT NULL, DEFAULT TRUE | 保存浏览历史 |
| is_active | BOOLEAN | NOT NULL, DEFAULT TRUE | 是否活跃（Django内置） |
| is_staff | BOOLEAN | NOT NULL, DEFAULT FALSE | 是否是管理员（Django内置） |
| is_superuser | BOOLEAN | NOT NULL, DEFAULT FALSE | 是否是超级用户（Django内置） |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**索引**：
- UNIQUE INDEX `idx_users_email` (`email`)
- UNIQUE INDEX `idx_users_username` (`username`)
- INDEX `idx_users_role` (`role`)
- INDEX `idx_users_status` (`status`)
- INDEX `idx_users_created_at` (`created_at`)

### 2.2 板块表（categories）

| 字段名 | 数据类型 | 约束 | 描述 |
| --- | --- | --- | --- |
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 板块ID |
| name | VARCHAR(50) | NOT NULL, UNIQUE | 板块名称 |
| description | TEXT | NOT NULL | 板块描述 |

| order | INT | NOT NULL, DEFAULT 0 | 排序顺序 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |

**索引**：
- UNIQUE INDEX `idx_categories_name` (`name`)

### 2.3 帖子表（posts）

| 字段名 | 数据类型 | 约束 | 描述 |
| --- | --- | --- | --- |
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 帖子ID |
| title | VARCHAR(255) | NOT NULL, INDEX | 帖子标题 |
| content | TEXT | NOT NULL | 帖子内容（支持富文本） |
| type | VARCHAR(20) | NOT NULL, DEFAULT 'normal', INDEX | 帖子类型 |
| media_files | JSON | NULL | 媒体文件URL数组（JSON格式，支持图片和视频） |
| user_id | BIGINT | NOT NULL, FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE | 用户ID |
| category_id | BIGINT | NOT NULL, FOREIGN KEY (category_id) REFERENCES categories(id) ON DELETE CASCADE | 板块ID |
| likes_count | INT | NOT NULL, DEFAULT 0 | 点赞数 |
| comments_count | INT | NOT NULL, DEFAULT 0 | 评论数 |
| views_count | INT | NOT NULL, DEFAULT 0 | 浏览数 |
| is_sticky | BOOLEAN | NOT NULL, DEFAULT FALSE, INDEX | 是否置顶 |
| is_essential | BOOLEAN | NOT NULL, DEFAULT FALSE, INDEX | 是否精华 |
| status | VARCHAR(20) | NOT NULL, DEFAULT 'normal', INDEX | 帖子状态 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP, INDEX | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**索引**：
- INDEX `idx_posts_user_id` (`user_id`, `created_at` DESC)
- INDEX `idx_posts_category_id` (`category_id`, `created_at` DESC)
- INDEX `idx_posts_type` (`type`, `created_at` DESC)
- INDEX `idx_posts_created_at` (`created_at` DESC)
- INDEX `idx_posts_is_sticky` (`is_sticky`, `is_essential`, `created_at` DESC)
- FULLTEXT INDEX `idx_posts_title_content` (`title`, `content`) | 用于搜索功能 |

## 4. 数据流程

### 4.1 用户注册流程
1. 用户提交注册信息（邮箱、用户名、密码）
2. 系统验证邮箱格式（必须是学校邮箱@xx.edu.cn）
3. 系统检查邮箱和用户名是否已存在
4. 系统使用bcrypt加密密码
5. 系统创建用户记录，默认角色为student
6. 系统返回JWT令牌

### 4.2 发帖流程
1. 用户选择板块，填写帖子内容
2. 系统验证用户权限
3. 系统保存帖子记录，关联用户和板块
4. 系统更新板块的postCount字段
5. 系统更新用户的postCount字段
6. 系统返回帖子详情

### 4.3 评论流程
1. 用户在帖子下填写评论内容
2. 系统验证用户权限
3. 系统保存评论记录，关联用户和帖子
4. 系统更新帖子的commentsCount字段
5. 系统更新用户的commentCount字段
6. 系统返回评论详情

### 4.4 点赞流程
1. 用户点击点赞按钮
2. 系统检查用户是否已点赞
3. 如果未点赞，系统创建点赞记录，更新目标对象的likesCount字段
4. 如果已点赞，系统删除点赞记录，更新目标对象的likesCount字段
5. 系统返回最新的点赞状态和点赞数

### 4.5 举报流程
1. 用户点击举报按钮
2. 用户选择举报类型，填写举报原因
3. 系统保存举报记录
4. 系统更新目标对象的状态为reported
5. 系统返回举报成功消息

### 4.6 管理员处理举报流程
1. 管理员查看举报列表
2. 管理员审核举报内容
3. 管理员选择处理动作（忽略/删除/警告）
4. 系统更新举报记录的状态和处理信息
5. 如果选择删除，系统更新目标对象的状态为deleted
6. 系统返回处理结果

## 5. 数据库优化

### 5.1 索引优化
- 为经常查询的字段创建索引
- 为外键字段创建索引
- 为搜索功能创建全文索引
- 避免过多索引，影响写入性能

### 5.2 查询优化
- 使用参数化查询，防止SQL注入
- 避免全表扫描
- 合理使用JOIN，避免笛卡尔积
- 限制查询结果数量，使用分页

### 5.3 性能优化
- 定期清理无用数据
- 定期优化表结构
- 合理设置数据库连接池
- 使用读写分离（可选，根据业务规模）

## 6. 数据库安全

### 6.1 访问控制
- 最小权限原则，为不同用户分配不同的数据库权限
- 定期更换数据库密码
- 使用加密连接（SSL）

### 6.2 数据加密
- 密码使用bcrypt加密存储
- 敏感数据加密传输
- 定期备份数据

### 6.3 防止SQL注入
- 使用参数化查询
- 输入验证和过滤
- 避免使用动态SQL

## 8. 数据库迁移和版本控制

- 使用Sequelize的迁移功能进行数据库版本控制
- 每次修改数据库结构时，创建对应的迁移文件
- 迁移文件包含up和down方法，支持数据库结构的升级和回滚
- 迁移文件命名格式：`YYYYMMDDHHMMSS-create-table-name.js`

## 11. 附录

### 11.1 数据类型说明

| 类型 | 描述 | 大小 |
| --- | --- | --- |
| BIGINT | 大整数 | 8字节 |
| INT | 整数 | 4字节 |
| VARCHAR | 可变长度字符串 | 1-255字节 |
| TEXT | 长文本 | 65,535字节 |
| DATETIME | 日期和时间 | 8字节 |
| BOOLEAN | 布尔值 | 1字节 |
| ENUM | 枚举类型 | 1-2字节 |
| JSON | JSON格式 | 可变 |

### 11.2 约束说明

| 约束 | 描述 |
| --- | --- |
| PRIMARY KEY | 主键约束，唯一标识一条记录 |
| FOREIGN KEY | 外键约束，关联其他表的主键 |
| NOT NULL | 非空约束，字段不能为NULL |
| UNIQUE | 唯一约束，字段值不能重复 |
| DEFAULT | 默认值约束，字段的默认值 |
| AUTO_INCREMENT | 自增约束，字段值自动递增 |
| ON DELETE CASCADE | 级联删除，当主表记录删除时，从表相关记录也删除 |
| ON DELETE SET NULL | 当主表记录删除时，从表相关字段设置为NULL |

### 11.3 索引类型说明

| 类型 | 描述 |
| --- | --- |
| PRIMARY INDEX | 主键索引，唯一且非空 |
| UNIQUE INDEX | 唯一索引，字段值唯一 |
| INDEX | 普通索引，提高查询效率 |
| FULLTEXT INDEX | 全文索引，用于文本搜索 |
