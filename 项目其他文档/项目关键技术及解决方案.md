# 校园信息聚合论坛系统（校园通）- 关键技术及解决方案

## 一、项目概述

校园信息聚合论坛系统（校园通）是一个基于前后端分离架构的校园社区平台，旨在解决大学校园内信息分散、获取不便的问题。系统整合了校园内的学习、生活、交易、活动等各类信息，为学生、教职工和商家提供便捷的信息交流渠道。

## 二、关键技术栈

| 类别 | 技术 | 版本 | 用途 |
| --- | --- | --- | --- |
| 后端框架 | Django | 5.x | Web服务器框架 |
| 数据库 | MySQL | 9.4 | 数据存储 |
| 后端API | Django REST Framework | 3.15+ | RESTful API开发 |
| 认证机制 | JWT | - | 用户认证与授权 |
| 前端框架 | React | 18.x | 前端UI框架 |
| 前端构建工具 | Vite | 5.x | 前端项目构建 |
| UI组件库 | Ant Design | 5.x | 前端UI组件 |
| HTTP客户端 | Axios | - | 前后端数据交互 |
| AI集成 | DeepSeek API | - | 智能问答、内容生成等AI功能 |

## 三、关键技术及解决方案

### 1. 前后端分离架构

**技术实现**：前端使用React + Vite + Ant Design，后端使用Django + Django REST Framework，通过RESTful API进行数据交互。

**解决方案**：
- 前端通过axios调用后端API，实现数据的获取和更新
- 后端使用Django REST Framework构建标准化的RESTful API
- 使用JWT进行身份认证，确保API调用的安全性
- 统一API响应格式，包含success、message和data字段，便于前端统一处理

**遇到的困难**：
- 前后端数据格式不一致（前端使用camelCase，后端使用snake_case）
- 解决方案：在前端API调用中添加数据转换逻辑，将后端返回的snake_case转换为camelCase

### 2. JWT认证机制

**技术实现**：使用django-rest-framework-simplejwt库实现JWT认证，包括token获取、刷新和验证。

**解决方案**：
- 在后端配置JWT认证视图和权限类
- 前端在请求头中添加Authorization字段，包含JWT token
- 实现token过期自动刷新机制
- 在localStorage中存储token，管理登录状态

**遇到的困难**：
- token过期处理
- 解决方案：实现axios响应拦截器，当遇到401错误时自动刷新token

### 3. RESTful API设计

**技术实现**：遵循RESTful API设计原则，设计标准化的API端点，包括资源获取、创建、更新和删除操作。

**解决方案**：
- 使用Django REST Framework的ViewSet和Router自动生成API端点
- 实现分页、过滤、排序等功能，提高API的灵活性
- 统一API响应格式，确保前后端数据交互的一致性
- 添加API文档，便于前端开发和调试

**遇到的困难**：
- Django APPEND_SLASH机制导致的POST请求重定向问题
- 解决方案：统一API端点的URL格式，确保所有API调用都使用正确的尾随斜杠

### 4. 组件化开发

**技术实现**：使用React组件化开发，将系统拆分为多个可复用的组件，如PostList、PostDetail、CommentList等。

**解决方案**：
- 设计合理的组件结构，提高代码复用性和可维护性
- 使用Ant Design组件库，减少重复开发
- 实现组件间的通信，确保数据的正确传递
- 添加组件测试，提高代码质量

**遇到的困难**：
- Ant Design v5组件用法变化（如Tabs组件从TabPane子组件改为items属性）
- 解决方案：更新组件用法，使用Ant Design v5推荐的写法

### 5. 状态管理

**技术实现**：使用React Context API进行全局状态管理，如登录状态、用户信息等。

**解决方案**：
- 创建AuthContext，管理用户的登录状态和基本信息
- 在组件中使用useContext钩子获取和更新状态
- 实现状态的持久化，如将用户角色保存到localStorage

**遇到的困难**：
- 组件状态与全局状态的同步
- 解决方案：使用useEffect钩子监听状态变化，确保UI与数据同步

### 6. 数据库设计

**技术实现**：使用Django ORM进行数据库操作，设计合理的数据库模型，包括User、Post、Comment、Category等。

**解决方案**：
- 设计规范化的数据库模型，减少数据冗余
- 使用Django迁移机制管理数据库结构的变化
- 添加适当的索引，提高查询性能
- 实现数据的软删除，便于数据恢复

**遇到的困难**：
- 自定义User模型的迁移问题
- 解决方案：按照Django文档的要求，正确配置自定义User模型，并生成迁移文件

### 7. AI功能集成

**技术实现**：集成DeepSeek API，实现智能问答、帖子创作辅助和智能搜索增强等功能。
