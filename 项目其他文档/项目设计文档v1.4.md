# 校园信息聚合论坛系统（校园通）项目设计文档v1.4

## 1. 项目概述

### 1.1 项目背景
校园信息聚合论坛系统（校园通）是为了解决大学校园内信息分散、获取不便的问题，旨在创建一个结构化、可搜索、可沉淀的校园社区平台。该系统将整合校园内的学习、生活、交易、活动等各类信息，为学生、教职工和商家提供便捷的信息交流渠道。

### 1.2 项目目标
- 解决校园信息差，提升学生生活质量
- 构建结构化、可搜索、可沉淀的校园社区
- 提供学生友好的用户体验
- 实现分类明确的七大功能板块
- 建立简单高效的分级权限管理系统

### 1.3 核心功能
- 用户注册登录系统（学校邮箱验证）
- 多级权限管理
- 七大功能板块内容管理
- 帖子发布、评论、点赞功能
- 搜索与筛选功能
- 管理员后台管理
- 广告发布与管理

## 4. 系统流程设计

### 4.1 用户注册流程

```
用户填写注册信息 → 系统验证学校邮箱格式 → 密码加密 → 创建用户记录 → 返回JWT令牌 → 登录成功
```

### 4.2 用户登录流程

```
用户填写登录信息 → 系统验证邮箱和密码 → 生成JWT令牌 → 返回JWT令牌 → 登录成功
```

### 4.3 发帖流程

```
用户选择板块 → 填写帖子内容 → 上传图片（可选） → 系统验证权限 → 保存帖子 → 更新用户发帖数 → 返回帖子详情
```

### 4.4 评论流程

```
用户查看帖子 → 填写评论内容 → 系统验证权限 → 保存评论 → 更新用户评论数 → 返回评论列表
```

### 4.5 管理员审核流程

```
用户举报内容 → 管理员查看举报列表 → 审核内容 → 处理（删除/忽略） → 更新举报状态
```

### 4.6 搜索流程

```
用户输入关键词 → 选择板块（可选） → 设置排序方式 → 系统查询数据库 → 返回搜索结果
```

## 5. 安全设计

### 5.1 数据安全
- 密码加密存储（bcrypt）
- JWT令牌认证
- 基础XSS防护（内容转义）
- SQL注入防护（Django ORM参数化查询）
- 敏感数据加密传输（HTTPS）

### 5.2 权限安全
- 角色权限验证中间件
- 基于角色的访问控制（RBAC）
- 敏感操作权限校验
- 管理员操作日志记录

### 5.3 系统安全
- 防止暴力破解（登录失败次数限制）
- 防止CSRF攻击（JWT令牌验证）
- 防止文件上传漏洞（文件类型和大小限制）
- 定期数据备份
