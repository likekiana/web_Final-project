1. **评论点赞数量增加两次问题**

3. **API调用返回404错误问题**
   - **原因**：前端API端点URL带有尾部斜杠，与后端Django路由不匹配
   - **解决**：移除了所有API端点URL中的尾部斜杠

   - **原因**：Ant Design v5不再支持Button组件的as属性
   - **解决**：将Button与Link组件的结合方式从`Button as={Link}`改为嵌套方式

   - **原因**：前端直接访问了不存在的user属性，且日期字段名与后端不匹配

6. **CategoryManagement组件类型无效问题**

7. **管理员登录后未跳转问题**
   - **原因**：登录成功后没有根据用户角色进行不同的跳转
   - **解决**：添加了根据用户角色的跳转逻辑

8. **管理员后台出现组件类型错误问题**

   - **解决**：改为使用TabPane组件作为子元素

9. **CategoryManagement组件类型错误问题**
   - **原因**：使用了过时的 `TabPane` 组件，而 antd v5 中 `Tabs` 组件已改为使用 `items` 属性
   - **解决**：将 `Tabs` 组件重构为使用 `items` 属性，移除 `TabPane` 导入

10. **Modal组件警告问题**
    - **原因**：使用了已废弃的 `visible` 属性，antd v5 推荐使用 `open` 属性
    - **解决**：将所有模态框的 `visible` 属性替换为 `open`

11. **管理员API端点配置问题**

### 问题分析与解决

1. **AI扩展内容相关性不高**
   - **原因**：关键词提取不准确，导致生成内容相关性不高
   - **解决**：优化关键词提取逻辑，使用多种分隔符分割文本，添加关键词去重和数量限制

2. **视频上传失败**
   - **原因**：前端显式设置Content-Type导致视频上传失败
   - **解决**：移除axios实例中显式设置的Content-Type，让浏览器自动设置带有边界字符串的multipart/form-data

3. **视频预览功能失效**
   - **原因**：根据URL扩展名判断视频类型失效
   - **解决**：保存文件MIME类型，根据类型渲染不同的预览组件（video或img）

4. **缺少删除确认机制**
   - **原因**：个人中心帖子删除功能没有确认机制，容易导致误操作
   - **解决**：添加删除确认对话框，使用Modal组件实现，让用户确认后再执行删除操作

5. **私信图片加载问题**
   - **原因**：前端错误地使用API URL作为媒体文件的基础URL，导致图片无法加载
   - **解决**：将API URL中的/api后缀替换掉，生成正确的媒体文件访问URL

6. **私信消息显示不友好**
   - **原因**：所有消息都显示在同一侧，没有区分发送者
   - **解决**：根据消息的sender.id与当前用户id比较，确定消息显示位置，我的消息显示在右侧，别人的消息显示在左侧

7. **前端文件上传UI不显示**
   - **原因**：文件列表管理不当，Upload组件配置错误
   - **解决**：手动管理媒体文件列表，使用状态存储上传文件，修复Upload组件配置

8. **文件上传路由配置问题**
   - **原因**：Django APPEND_SLASH=True导致POST请求重定向失败
   - **解决**：在post_urls.py中添加文件上传路由，同时支持upload和upload/URL

const AIAssistant = () => {
    const [messages, setMessages] = useState([])
    const [inputValue, setInputValue] = useState('')

            id: Date.now(),
            text: inputValue,
            isUser: true
        }
        
        setMessages(prev => [...prev, userMessage])

            console.error('AI response failed:', error)
        } finally {
            setLoading(false)
        }
    }
    
    return (
        <div className="ai-assistant">
            <div className="messages-container">
                {messages.map(message => (
                    <div key={message.id} className={`message ${message.isUser ? 'user' : 'ai'}`}>
