## 注册说明
1. 注册需要使用学校邮箱（必须以 `.edu.cn` 结尾）
2. 密码长度至少6个字符
3. 注册成功后会自动生成 JWT 令牌




## 测试账号（可选）
如果需要测试账号，可以使用以下命令生成：
```bash
python manage.py generate_test_accounts
```
